# 🎮 Tic Tac Toe Game

A fun, fully playable two-player Tic Tac Toe game built with vanilla **HTML5, CSS3, and JavaScript** — no frameworks, no libraries, just clean front-end fundamentals.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## ✨ Features

- 🎯 Two-player gameplay (X vs O)
- 🏆 Win-detection logic across all winning combinations
- 🤝 Draw detection when the board fills with no winner
- 🔄 Reset and New Game buttons
- 🌌 Purple galaxy theme
- 📱 Responsive design — playable on mobile and desktop
- ✨ Animated UI for a polished feel

## 🛠️ Tech Stack

- **HTML5** — structure and layout
- **CSS3** — styling, animations, and responsive design
- **JavaScript** — game logic, win/draw detection, and DOM interaction

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/aqsaishtiaq19/tic-tac-toe.git
   ```
2. Open `index.html` in your browser — no build step or dependencies required.

## 🎲 How to Play

1. Player 1 (X) and Player 2 (O) take turns clicking on empty squares.
2. The first player to align three of their marks — horizontally, vertically, or diagonally — wins.
3. If all nine squares fill up with no winner, it's a draw.
4. Click **Reset** to clear the board, or **New Game** to start fresh.
